About the project

webserv is a custom HTTP/1.1 server written in C++. This homepage doubles as a live README + evaluation test surface.

  • Protocol=HTTP/1.1
  • Methods=GET / POST / DELETE
  • Upload=server-native + CGI paths
  • Bodies=Content-Length + chunked

Live server tests

Use the actions below during evaluation to demonstrate behavior quickly. The result codes may vary depending on your config (201/204/303 can all be valid).

GET / (home) GET /uploads/ (if enabled) GET /uploads/test.txt GET /nope (404)
